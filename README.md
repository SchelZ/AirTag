Created using EasyEDA Pro.
- This project presents a small self made AirTag that replicates Apple Airtag. 
- 4 layer PCB
- Using BLE to ping Apple devices around it to find its position on map inspired from this project: https://github.com/seemoo-lab/openhaystack
